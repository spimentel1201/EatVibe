# Mobile - FoodRush

Aplicación móvil de FoodRush para iOS y Android.

## 🚀 Stack Tecnológico

- React Native / Flutter (por definir)
- TypeScript
- Expo (si se usa React Native)
- Redux / MobX (State Management)
- React Navigation

## 📱 Características

- Registro y login con OAuth2
- Búsqueda geoespacial de restaurantes
- Carrito de compras persistente
- Procesamiento de pagos
- Tracking en tiempo real
- Notificaciones push

## 🛠️ Desarrollo

### Instalación
```bash
npm install
# o
yarn install
```

### Ejecutar en desarrollo
```bash
npm start
# o
yarn start
```

### Ejecutar en iOS
```bash
npm run ios
# o
yarn ios
```

### Ejecutar en Android
```bash
npm run android
# o
yarn android
```

## 📝 Convenciones

- TypeScript estricto
- Componentes funcionales con Hooks
- Atomic Design para componentes
- Tests con Jest y React Native Testing Library
