# Web - FoodRush

Aplicación web de FoodRush (Dashboard para restaurantes y administración).

## 🚀 Stack Tecnológico

- React / Next.js
- TypeScript
- TailwindCSS
- Redux Toolkit / Zustand
- React Query
- Axios

## 🎨 Características

- Dashboard de restaurantes
- Gestión de menús y stock
- Panel de pedidos en tiempo real
- Estadísticas y reportes
- Backoffice de administración

## 🛠️ Desarrollo

### Instalación
```bash
npm install
# o
yarn install
```

### Ejecutar en desarrollo
```bash
npm run dev
# o
yarn dev
```

### Build de producción
```bash
npm run build
# o
yarn build
```

### Ejecutar producción
```bash
npm start
# o
yarn start
```

## 📝 Convenciones

- TypeScript estricto
- Componentes funcionales con Hooks
- Atomic Design para componentes
- CSS Modules o TailwindCSS
- Tests con Jest y React Testing Library
